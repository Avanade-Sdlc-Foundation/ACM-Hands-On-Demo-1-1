# Hands-on: ウェブサイト動作テストの作成

AIアシスタント（GitHub Copilot Chat）を使って、ウェブサイトの動作テストを作る実践的な演習です。Smart Bookmarksウェブサイトを使って、テストの設計からコード作成まで一連の流れを学習します。

## 演習の概要

> [!IMPORTANT]
> この演習で使用するAIツールは学習に基づいて動作するため、説明のスクリーンショットや
> コードと実際の結果に違いが生じる場合があります。

この演習では、AIアシスタントを使ってウェブサイトの動作テストを作る方法を順番に学びます。

0. [環境の準備と設定](./0-prereqs.md)
1. [ウェブサイトの探索と機能理解](./1-explore-website.md)  
2. [AIアシスタントを使ったテストコード作成](./3-generate-tests.md)

## シナリオ

あなたはSmart Bookmarksという書籍管理ウェブサイトの品質管理チームのメンバーです。新しい機能のリリース前に、主要な機能が正常に動作することを確認するテストの作成が必要になりました。

実際にウェブサイトを操作してどのような機能があるかを理解し、次にGitHub Copilot Chatに適切な指示を出してPlaywrightテストコードを生成します。AIアシスタントとの効果的なコミュニケーション技術を習得し、手動では数時間かかるテストコード作成を数分で完了させる効率的な開発手法を学びます。

## この演習で学べること

このハンズオンを完了すると、以下のスキルを習得できます：

- **AIアシスタントの効果的な使い方**: 適切な指示を作成してテストコードを生成する技術
- **ウェブテストの基本理解**: ブラウザ自動化テストの基本概念と作成パターン
- **カスタム指示の活用**: プロジェクト固有のルールに従ったコード生成
- **テストコードの読解力**: 生成されたテストコードの構造と意図を理解する能力
