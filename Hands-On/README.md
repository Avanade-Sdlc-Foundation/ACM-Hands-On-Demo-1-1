# Hands-on: ウェブアプリケーションのE2Eテストケース作成

GitHub Copilot Chatを活用してPlaywrightによるE2Eテストケースを作成する実践的な演習です。Smart Bookmarksウェブサイトを題材に、テスト設計からコード生成まで一連のプロセスを学習します。

## ラボの概要

> [!IMPORTANT]
> このラボの技術や生成AIツールは確率論的であるため、スクリーンショットや
> コードスニペットと実際の体験に違いが生じる可能性があります。

このラボでは、GitHub Copilot Chatを使用してウェブアプリケーションのE2Eテストケースを作成する方法を順を追って説明します。

0. [前提条件と環境設定](./0-prereqs.md)
1. [ウェブサイトの探索と機能理解](./1-explore-website.md)  
2. [開発環境のセットアップ](./2-setup-environment.md)
3. [GitHub Copilot Chatによるテストコード生成](./3-generate-tests.md)

## シナリオ

あなたは、Smart Bookmarksという書籍管理ウェブアプリケーションの品質保証チームの一員です。新しい機能リリース前に、主要な機能が正常に動作することを確認するE2Eテストの実装が必要になりました。

従来の手動テスト作成では時間がかかりすぎるため、GitHub Copilot Chatを活用して効率的にPlaywrightテストコードを生成し、継続的インテグレーションに組み込める自動テストスイートを構築します。

## 学習目標

このハンズオンを完了すると、以下のスキルを習得できます：

- **GitHub Copilot Chatの効果的な活用**: 適切なプロンプトを作成してE2Eテストコードを生成する技術
- **Playwrightテスト設計理解**: ブラウザ自動化テストの基本概念と実装パターン
- **Custom指示の活用**: プロジェクト固有のコーディング規約に従ったコード生成
- **テストコードの読解力**: 生成されたテストコードの構造と意図を理解する能力
